# Huong dan su dung project
- Cai dat nodejs len may (https://nodejs.org/en/download)
- cai phan git len may de cai dat du an (https://git-scm.com/)
- khi tai du an tu github ve thi doi ten file .env.example thanh file .env va cau hinh cac thong so vao trong do
- sau do chay lenh : npm install (cai dat cac thu vien tu file package.json)
# chay du an
- su dung lenh : 
   - chay danh cho dev : npm run dev
   - chay danh cho product: npm start
